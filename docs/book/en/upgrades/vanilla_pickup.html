Pickup Upgrade

Allow golems to pick up items and experiences. The pickup radius increase with upgrade level. Max: 3

There are 2 Augments available, also it supports L2Backpack and Create Enchantment Industry as destination to receive items and experiences.

Note that golem will not actively find items and experiences.
The golem will attempt to teleport the item to player. If it's in standing mode, it will first try to put the items into the closest container within 1 blocks. If neither container nor the player is present, it will destroy the item to prevent lag. If the golem has No Destroy Augment, it will not destroy the item.
The golem will first try to use the experiences to fix its mending equipments. Then if the golem has Mending Augment, it will try to heal itself with the experiences. Then, if the player is present, it will give the experiences to player. Otherwise, it will destroy the experiences.
If you installed L2Backpack, golem can use Dimensional Backpack and will try to insert items into its Dimensional Backpack before searching for containers.

If you installed Create Enchantment Industry, golem will try to insert experiences into the disenchanter if it stands on one, before trying to teleport the items to player.

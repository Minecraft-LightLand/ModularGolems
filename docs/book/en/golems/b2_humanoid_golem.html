Humanoid Golem

Humanoid golem is a player-like golem. It can use armor, meelee weapons, bows, crossbows, trident, and shield. Right click the golem with equipments to equip, and shift-right click the golem to un-equip all. If you shift-right click with empty hand, the golem will be retrieved naked as well. Right click the golem with empty hand to retrieve the golem with equipments stored within.
→
Humanoid golem can perform area attack if and only if it holds a sword-like item.

Humanoid golem can use shield, trident, bow, and crossbow.
Use the Skin Button in the Humanoid Golem equipment screen to change its skin.

Supported input formats:

Player Name - Use the Minecraft skin of a player
Resource Path - Use a custom texture from resource packs, e.g.:
modulargolems:textures/iws2000.png
Entity id() - Use texture from vanilla zombie / skeleton / piglin variants, e.g.:
minecraft:drowned

Right-click the button to reset to default skin.
If Touhou Little Maid is installed, use the Maid Skin Button in the equipment screen to switch to a maid model.

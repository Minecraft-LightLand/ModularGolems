Squad Wand

Right click golem to set it as captain. Golems must have config card in order to be a captain. Each config card may only have one captain.

When a non-captain golem is set to Squad mode, it will follow the captain of the same config card. Captain should not have be in squad mode, as it needs to lead the team.

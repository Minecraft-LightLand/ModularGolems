Golem Slicing Axe

Golem Slicing Axe
When a metal golem kills other players‘ golems without recycle upgrade with this axe, all parts will be dropped and there is a chance for each of the upgrades to drop.

Edit the target filter in config card to allow golems to attack other golems. Note that golems cannot attack golems you own.
When a metal golem kills certain mobs with this axe, one random metal golem part with matching material will drop:
Vanilla: Iron Golem, Warden
Cataclysm: Netherite Monstrosity, Ignis, Harbinger, Maledictus, Scylla, Ancient Remnant
Mowzie's Mobs: Ferrous Wroughtnaut
Legendary Monsters: Ancient Guardian, Cloud Golem
